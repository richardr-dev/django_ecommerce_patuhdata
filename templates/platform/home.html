Yang sering ditanyakan

Apakah benar gratis?

Ya. Paket {{ free_plan.name|default:"Gratis" }} tidak memiliki biaya bulanan dan memuat {% if free_plan.max_products is not None %}hingga {{ free_plan.max_products }} produk aktif{% else %}produk tanpa batas{% endif %}. Upgrade ke paket berbayar hanya jika Anda membutuhkan lebih banyak produk atau domain sendiri.

Perlu keahlian teknis untuk membuat toko?

Tidak. Pilih template tampilan, unggah logo dan produk, lalu toko siap dibagikan. Semua pengaturan dilakukan dari back office berbahasa Indonesia.

Bisakah memakai domain sendiri?

Bisa, di paket berbayar. Arahkan DNS domain Anda ke {{ platform_name }} dan sertifikat HTTPS diterbitkan otomatis.

Apakah langganan diperpanjang otomatis?

Tidak. Anda membayar per periode (1 atau 12 bulan) dari menu Langganan. Jika tidak diperpanjang, toko tetap aktif di paket Gratis dan produk Anda tidak dihapus.

Bagaimana data toko dan pelanggan dijaga?

Setiap toko terisolasi: produk, pesanan, dan pelanggan hanya dapat diakses pemilik dan staf toko tersebut. Seluruh koneksi memakai HTTPS. Selengkapnya di kebijakan privasi.
