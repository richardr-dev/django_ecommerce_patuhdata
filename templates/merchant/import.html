Panduan SKU

Agar pesanan berhasil diimpor dan stok otomatis terpotong:

{% if platform == "shopee" %}
  1. Buka Shopee Seller Center → Produk
  2. Edit setiap produk → isi kolom Nomor Referensi SKU
  3. Pastikan SKU sama persis dengan yang ada di katalog Lakuin
  4. Ekspor ulang pesanan, lalu upload di sini

Jika SKU belum diisi, centang "Impor data historis" agar pesanan tetap masuk tanpa potong stok.

{% elif platform == "tokopedia" %}
  1. Buka Tokopedia Seller Center → Produk
  2. Edit setiap produk → isi kolom SKU (Stock Keeping Unit)
  3. Pastikan SKU sama persis dengan yang ada di katalog Lakuin
  4. Ekspor ulang pesanan dalam format .xlsx, lalu upload di sini

Jika SKU kosong, centang "Impor data historis" — produk placeholder akan dibuat otomatis.

{% else %}
  1. Pastikan kolom sku di CSV terisi dengan SKU yang ada di katalog Lakuin
  2. Cek SKU di Katalog → Semua Produk
  3. Jika belum ada produk, tambahkan dulu atau gunakan mode historis
{% endif %}
